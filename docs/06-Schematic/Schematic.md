##Overview 

This schematic is designed to support the environmental Sensor Subsystem Board. It regulates a DC 9V wall adapter input down to 3.3V using an LM2575T-3.3G switchiung regulator with diode and fuse protection. The 3.3V rail powers a PIC18F57Q43 48 pin microcontroller that monitors a all in 1 temperature, humidity, pressure, and gas monitoring sensor. The system provides stable sensor inputs, onboard filtering, expansion Pins, and a ribbon connector for inter-board communication.”

## 📦 Project Resources

This page contains all final supporting files for the Temperature Subsystem PCB project, including firmware, design files, and optional media documentation.

---

## 💻 Firmware Project

The final embedded firmware was developed in MPLabX for the PIC18F57Q43 microcontroller. The code handles I2C communication with the TC74 temperature sensor and transmits temperature data through the subsystem communication interface.

📁 **MPLabX Project (ZIP):**  
`/firmware/MPLabX_temperature_project.zip`
